# Karthick V Portfolio — Minecraft-Styled Ubuntu Simulation

Welcome to my personal developer portfolio! This is a unique, fully interactive website designed as a **Minecraft-styled Ubuntu Linux desktop operating system simulation**. It showcases my backend engineering capabilities, Python developments, and agentic AI systems.

Live URL: [https://gorghs.github.io/](https://gorghs.github.io/)

---

## 🚀 Key Features

- **Interactive OS Desktop**: Mimics a live Ubuntu Linux desktop with draggable icons, window controls, and launcher docks.
- **Minecraft Aesthetic**: Re-designed Yaru app launchers, custom blocky inventory hotbars, and active item indicators.
- **Cinematic Transition Background**: A scroll-driven, infinite-zoom Droste-effect camera transition that guides you from the Minecraft Cabin entrance to the "Still Building" island.
- **Fully Loaded Applications**:
  - **Firefox Web Browser**: Rebranded browser pre-configured to open my resume page in fullscreen.
  - **Terminal**: Interactive shell supporting standard Linux commands (`cd`, `ls`, `pwd`, `mkdir`, `clear`) alongside customized launchers (`spotify`, `vscode`, `about-karthick`).
  - **Gedit (Contact Me)**: Custom form linked to FormSubmit.co via AJAX with an error fallback.
  - **Spotify Integration**: Embeds my curated developer playlists.
- **Responsive Layout**: Designed to automatically transition to relative scrolling lists on mobile and tablet screen widths.

---

## 🛠️ Tech Stack

- **Core**: Next.js, React, JavaScript, JQuery
- **Styling**: Tailwind CSS, Vanilla CSS
- **Integrations**: FormSubmit.co, React-GA4, React-Draggable

## 📖 Local Setup and Running

1. Clone or download this repository.
2. Install npm dependencies in the root folder:
   ```bash
   npm install
   ```
3. Start the Next.js development server:
   ```bash
   npm run dev
   ```
4. Access the simulated desktop locally at [http://localhost:3000/](http://localhost:3000/).
